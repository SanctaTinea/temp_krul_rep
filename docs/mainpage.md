# Krul, transport и serde {#mainpage}

Krul — не зависящий от формата диспетчер команд, который не использует кучу.
Он проверяет запрос по статической схеме команд, вызывает обработчик приложения,
проверяет результат обработчика и формирует ответ с исходным идентификатором
транзакции. Один и тот же путь диспетчеризации поддерживает синхронные и
отложенные обработчики.

serde — слой сериализации, лежащий в основе Krul. Он предоставляет компактные
интерфейсы чтения и потоковой записи через таблицу методов и контекст реализации.
В комплект входят JSON-кодек на основе jsmn и прямой heap-free BSON-кодек;
Krul не зависит от типов, специфичных для конкретной сериализации.

Физические UART, TCP, USB, DMA и обратное давление остаются ответственностью
приложения. Самостоятельная библиотека `Libs/transport` предоставляет общий
потоковый framing/parser с
CRC для JSON, BSON и CBOR, не выполняя ввод-вывод самостоятельно.

- @ref json_protocol_v4 — нормативная спецификация Krul версии 4;

- @ref transport_v1 — framing `KRJ1`/`KRB1`/`KRC1`, длина и CRC;
- @ref krul — API команд;

Все три библиотеки используют переданное вызывающей стороной хранилище фиксированного
размера и не выделяют память в куче.

## Сборка документации

Из корневого каталога репозитория:

```powershell
doxygen Doxyfile
```

Если Doxygen установлен до конфигурирования CMake, также доступна эквивалентная
цель:

```powershell
cmake --build --preset PC_Debug --target docs
```

Начальная HTML-страница находится в `build/doxygen/html/index.html`.
